## 1. Quick Start Walkthrough

Getting started with HyperClick Pro 2026 takes less than 30 seconds:

```
+-------------------------------------------------------------------------+
| [ STEP 1: Launch ] ──▶ [ STEP 2: Pick Mode ] ──▶ [ STEP 3: Press F6 ]   |
| Run HyperClick Pro      Select CPS / Preset        Toggle ON/OFF        |
+-------------------------------------------------------------------------+
```

1. **Launch HyperClick Pro**: Open the application via Start Menu, Desktop shortcut, or portable binary.
2. **Select Target CPS or Preset**:
   - Choose a preset from the top dropdown (e.g., *Accessibility Steady Assist* or *Spreadsheet Automation*).
   - Alternatively, adjust the **Interval Slider** to your desired milliseconds ($ms$) or clicks-per-second ($CPS$).
3. **Select Click Button & Mode**: Choose **Left Click**, **Right Click**, **Middle Click**, or **Double Click**.
4. **Enter Your Target Application**: Switch to your work or game window.
5. **Press <kbd>F6</kbd> to Start/Stop**: HyperClick Pro will begin clicking instantly. The mechanical audio synthesizer provides acoustic feedback, and the Mini HUD tracks your live CPS.
6. **Press <kbd>F9</kbd> in Emergency**: To immediately stop all automation, press the <kbd>F9</kbd> Emergency Killswitch.

## 3. Single-Point Auto-Clicker Engine

### 3.1 Interval Configuration
HyperClick Pro allows precision down to the microsecond level ($\mu\text{s}$):
- **Hours, Minutes, Seconds**: For slow automation (e.g., clicking once every 10 minutes to prevent system sleep).
- **Milliseconds ($ms$)**: The standard unit for rapid clicking.
  $$\text{CPS} = \frac{1000}{\text{Interval in ms}}$$
  - $250\text{ ms} = 4\text{ CPS}$ (Gentle accessibility assist)
  - $50\text{ ms} = 20\text{ CPS}$ (Standard fast click)
  - $20\text{ ms} = 50\text{ CPS}$ (Speed test benchmark)
  - $2\text{ ms} = 500\text{ CPS}$ (QA software stress test)

### 3.2 Click Modes & Buttons
- **Left Click**: Primary action click.
- **Right Click**: Secondary interaction click.
- **Middle Click**: Scroll-wheel click.
- **Double Click**: Sends two rapid left clicks within 15ms of each other.
- **Triple Click**: Sends three clicks in rapid succession.
- **Hold Down Mode**: Keeps the mouse button depressed continuously until toggled off.

### 3.3 Repeat Limits vs Continuous Loop
- **Infinite (Until Stopped)**: Clicks continuously until <kbd>F6</kbd> or <kbd>F9</kbd> is triggered.
- **Fixed Count**: Stops automatically after sending an exact number of clicks (e.g., exactly 100 clicks).
- **Time Duration Limit**: Runs for a specified timeframe (e.g., run for 45 seconds, then stop).

## 4. Coordinate Loupe & Multi-Display Calibration

HyperClick Pro supports multi-monitor setups with disparate DPI scalings (100%, 125%, 150%, 200% 4K displays).

### 4.1 Using the 5x Magnifier Loupe
1. Click the **Pick Coordinates** button or press <kbd>F7</kbd>.
2. A crosshair loupe will follow your cursor across any monitor, magnifying the pixel grid at 500% zoom.
3. The real-time pixel coordinates $(X, Y)$ and Hex color code (`#RRGGBB`) are rendered below the crosshair.
4. **Left-click** anywhere to lock the target coordinate into HyperClick Pro.
5. Press <kbd>ESC</kbd> to cancel coordinate picking.

## 5. Ergonomic Rhythm & Natural Motion Assist

HyperClick Pro includes an **Ergonomic Rhythm Engine** designed to prevent muscle fatigue and provide a natural, organic clicking flow for long sessions.

```
  NATURAL HUMAN CADENCE                   RIGID ROBOTIC CLICKS
         ▲                                       ▲
         │       ___                             │       │
         │     /     \                           │       │
         │    /       \                          │       │
Frequency│  /           \               Frequency│       │
         │ /             \                       │       │
         └─────────────────►                     └───────┴─────────►
           Interval (ms)                           Interval (ms)
```

### 5.1 The Mathematical Model (Box-Muller Transform)
When Natural Rhythm Assist is enabled, click delays are sampled dynamically from a normal distribution curve $N(\mu, \sigma^2)$:

$$T_{\text{delay}} = \mu + \sigma \cdot \sqrt{-2 \ln(U_1)} \cos(2\pi U_2)$$

### 5.2 Micro-Fatigue & Rest Pauses
- **Periodic Hesitations**: Every 30–60 clicks, a minor 100–250ms pause is simulated.
- **Organic Motion**: Prevents unnatural constant clicking strain.
